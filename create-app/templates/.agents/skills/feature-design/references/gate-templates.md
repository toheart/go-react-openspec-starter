# Gate 模板

## 通用流程

1. 先汇总上一阶段的结论与待确认项。
2. 非信任模式下，给用户三个选项：通过、修改、停止。
3. 信任模式下，输出 `[信任通过]` 与简短理由，然后继续。

## gate-design

摘要应至少覆盖：

- 需求目标与非目标
- 关键设计决策
- 后端任务与前端任务拆分
- design-review 结论：C1-C5、M1-M5、Bad Path 四维审查、覆盖矩阵
- 错误响应契约是否已写入 `design.md`
- 测试入口是否明确；`test-plan.md` 将在 `test-design` 生成
- 剩余风险

非信任模式参考输出：

```text
## Gate: 设计确认

<方案摘要>

选项：
1. 通过，进入测试设计
2. 需要修改
3. 停止本次变更
```

信任模式参考输出：

```text
## [信任通过] Gate: 设计确认

<方案摘要>

通过理由：OpenSpec 方案、任务拆分与 design-review 结论已经齐备，可以进入测试设计。
```
